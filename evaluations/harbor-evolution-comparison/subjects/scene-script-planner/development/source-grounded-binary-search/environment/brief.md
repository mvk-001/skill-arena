# Scene Brief

- Status: Spike
- Target runtime: 24 seconds
- Audience: First-year computer science students who know arrays but not search algorithms.
- Primary idea: Each comparison in binary search removes half of the remaining sorted interval.
- Learning outcome: The viewer can explain why the visible search region shrinks after every comparison.
- Visual constraint: Use one horizontal sorted array, one target marker, and a visibly shrinking active interval.
- Pacing constraint: Use at least three story beats and end with the target isolated.
- Reuse prompt: Identify the shrinking-interval treatment as a candidate, not an approved component.
